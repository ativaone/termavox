# Security policy

## Supported versions

Termdock is pre-release: there is no tagged version yet. Security fixes land on the `main`
branch only, and only `main` is supported. This section will list supported releases once
v0.1.0 is out.

## Reporting a vulnerability

Termdock does not have a dedicated security contact yet. The maintainers will publish one here
before the first release.

Until then, please do not post vulnerability details in public issues, pull requests or
discussions.

## Security model

How Termdock is meant to be deployed, what it protects against, what it does not, and the
controls it relies on are described in [`docs/security.md`](docs/security.md).
